# Mario Di Pesa portfolio — V3

Static site for Cloudflare Pages. Upload the **contents** of this folder to the root of the GitHub repository (not the ZIP itself). No build step required; output directory `.`.

New in V3:
- `bioshock.html` — BioShock 2 / Minerva’s Den case study
- `weird-west.html` — Weird West case study
- Updated `games.html` with featured, clickable case studies
- Additional responsive styling in `styles.css`

Artwork panels are intentionally labeled placeholders. Replace only with verified, authorized screenshots. Case-study copy is a working draft for the site owner to approve.
